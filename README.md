## 🚀 Running Locally

No build tools or heavy dependencies required! Simply clone and open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/Nehasrisankaran/My-portfolio.git

# Open directly in browser
start index.html
```

Or run a lightweight local static server using Python or Node:

```bash
# Using Python
python -m http.server 8080

# Or using Node / npx
npx serve .
```
Then visit `http://localhost:8080`.
